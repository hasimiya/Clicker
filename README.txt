
Краткое описание структуры проекта:
Проект разделен на несколько ключевых скриптов согласно принципу единой ответственности (SOLID):
•	PlayerInputHandler.cs: Отвечает исключительно за чтение ввода с устройств (мышь/тачскрин) с помощью новой системы Input System и передачу команд дальше.
•	PlayerMovement.cs: Реализует универсальную логику движения объекта. Принимает команду о цели и плавно перемещает объект, используя Rigidbody2D.MovePosition для корректной работы с физикой.
•	UIManager.cs: Управляет элементами UI, в частности, слайдером скорости, и передает его значение в скрипт движения, не смешиваясь с игровой логикой.
•	GameManager.cs: Устанавливает целевую частоту кадров (FPS) для приложения на 60 кадров в секунду.
Принятые технические решения:
1)	Очередь команд. Для реализации последовательного движения по точкам использована структура данных Queue<Vector2>, что гарантирует порядок выполнения команд.
2)	Плавное движение. Для перемещения объекта используется связка Vector2.SmoothDamp и Rigidbody2D.MovePosition, так как это позволяет добиться плавного движения с замедлением у цели, сохраняя при этом корректные физические взаимодействия (в отличие от прямого изменения transform.position).
3)	Адаптивный UI. Для фона и интерфейса использовалась система Canvas для адаптивности на разных разрешениях экрана.
